# 珊瑚直播间 · 排品脚本与商品挂链审核系统

直播间排品、讲解脚本版本、商品资料审核、挂链检查、样品登记与发布回执的一体化演示系统。
**零第三方依赖**：仅使用 Node.js 22 内置的 `node:sqlite` 与 `node:http`。

## 单条命令启动

```bash
npm start          # 等价于 node src/server.js
# 或指定端口 / 重建演示数据
node src/server.js --reset --port 4000
```

打开 http://localhost:4000 。启动时自动创建演示样例：

- 1 个直播间 + 1 场「周三好物场」，4 个在排商品、1 个临时撤品（自动下架挂链）；
- 商品资料审核回执、脚本审核回执（模拟适配器，进程内）；
- 1 笔成交订单 + 重复/乱序变价回调样例（验证幂等与订单保护）；
- 本地样品照片（`data/samples/`）与「样品不符 → 补样 → 工单关闭」闭环。

`--reset` 清空 SQLite 后重建样例。演示账号：`a1` 珊瑚酱（主播/脚本人）、`r1`/`r2` 审核人。

## 功能

| 模块 | 说明 |
| --- | --- |
| 场次编排 | 横向时间轴，商品卡固定显示图片、库存、挂链状态；设置顺序、讲解时长、库存提示、优惠版本 |
| 脚本编辑 | 每次保存生成新版本；编辑器右侧同步显示违规词/版本/审核/挂链提示；发布按钮固定在右上角 |
| 商品审核 | 商品必须先通过资料审核才能加入排品；审核产生模拟回执 |
| 挂链检查 | 缺货自动下架、价格变更挂起核对、链接失效标记 `dead`，分别生成异常工单 |
| 样品登记 | 照片存本地目录 `data/samples/`；样品不符自动开工单 |
| 发布回执 | 发布前校验整场挂链与脚本；生成不可变发布快照与平台回执（幂等） |

## 关键业务规则

- **版本快照**：脚本修改即产生版本；场次发布生成整场快照，开场后排品锁定，继续使用发布快照，草稿不能覆盖，直播中禁止重复发布。
- **挂链唯一**：同一场内同一商品仅允许一条 `active` 挂链（SQLite 部分唯一索引兜底）；下架后才能换链；一条挂链不得绑给不同商品。
- **价格校验**：挂链价必须等于商品当前价，否则拒绝创建；变价后发布被拦截。
- **回调处理**：`eventKey` 去重（重复回调不重复上下架），`seq` 单调（乱序旧事件丢弃）；回调变价只改挂链现价，**已成交订单价格永不改变**。
- **审核权限**：审核人不能审核自己编写的脚本，参与过任一历史版本编辑同样拦截。
- **异常分流**：缺货 / 价格变更 / 链接失效 / 样品不符 / 违规词 / 临时撤品分别落不同工单类型。
- **违规词**：全局词（第一、绝无仅有、永久）+ 商品自带词（如 p6「最顶级」「国家级」），发布脚本与整场发布时双重校验。

## 存储

- SQLite：`data/livepick.db`（场次、排品、脚本与版本、审核、挂链、事件、订单、样品、工单、回执索引）。
- 本地目录：`data/samples/`（样品照片），`public/assets/img/`（启动时生成的商品 SVG）。
- 进程内模拟适配器：商品/主播/价格目录（`src/adapters.js`）、审核回执、发布回执；重启恢复初始演示状态。

## 模拟平台波动（用于演示）

```bash
# 商家变价 / 缺货 / 链接失效
curl -X POST localhost:4000/api/sim/products/p2 -H 'Content-Type: application/json' \
  -d '{"priceCents":9900}'
# 平台异步回调（可重复、可乱序）
curl -X POST localhost:4000/api/callbacks -H 'Content-Type: application/json' \
  -d '{"eventKey":"k1","linkId":"link_xxx","type":"delist","seq":1}'
```

## 目录结构

```
src/
  db.js        SQLite schema 与迁移
  adapters.js  商品/主播/价格 + 审核/发布回执（进程内模拟）
  services.js  全部领域规则（HTTP 层与测试共用）
  seed.js      启动演示样例
  assets.js    商品 SVG 生成
  server.js    零依赖 HTTP 服务 + API
public/        前端（石墨黑 #2B2B33 / 奶油白 #FBF6EC / 珊瑚色 #FF6B6B）
test/          node:test 用例
```
